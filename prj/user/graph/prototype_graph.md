# Прототип графического окна

Соотношение - примерно 1х2
Соответственно, подгоняем под реальный размер - добавляем поля

Windows/Linux - нужно брать высоту экрана и сразу отрезать все полосы и рамки окон, а затем убирать еще процентов 10-15
Оставшееся - опорная высота, от которой можно вниз подбирать высоту игрового окна.

~ 47х94 БК
или
50х100 БК

При разрешении ~ 1000 x 2000 БК = 20

Разрешение - 961х1708
Поле - 50х100 БК
1708/961 = 1,77 < 2 - идем от высоты:
1708/100 = 17,08 -> БК = 17 пикселя
Поля по высоте = (1708 - 17*100)/2 = 4 пикселя
Поле в высоту = 1700 пикселей
Поля по ширине: (961 - 17*50)/2 = 27,75 (слева - 27 пикселей)
Поле в  ширину = 850 пикселей

Если высота/ширину < 2 -> идем от высоты
Если > 2 -> идем от ширины
