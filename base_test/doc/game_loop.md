# Игровой цикл

Программа
	Заставка
	Начальное меню (выбор настроек игры)
	Игра
        Меню/заставка - для сообщения правил раунда (или выбора настроек (возможно!))
		Цикл игры (раунды)
			Генерация раунда
			Начальное заполнение слоев (если есть)
			Цикл раунда
				Генерация фигуры
				Проверка (если уперлись сразу - выход из раунда)
				Тактовый цикл
					Реализация действий пользователя
					Реализация игровых действий
					Проверки!
					Перерисовка
					Пауза
				Тактовый цикл
				Удаление фигуры и переход ее в слои
				Цикл удаления кубиков в слоях по правилам раунда
			Цикл раунда
			Если раунд полностью выполнен и не уперлись - новый раунд.
			Финальная картинка раунда.
		Цикл игры 
	Конец игры
	Меню новая игра/выход
	Финальная заставка
