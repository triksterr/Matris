# Игровой цикл

```
main - запуск game

App - вся программа (от запуска application - до выхода)
	Старт
	Заставка
	Чтение настроек из файла
	Начальное меню (выбор настроек игры) - запись в файл
	Затем, собственно сама игра:
	Game - цикл уровней (раундов) - собственно сама игра: от старта  до выигрыша/проигрыша
		Генерация раунда
		Меню/заставка - для сообщения правил раунда
		Начальное заполнение слоев (если есть)
		Round - цикл фигур при одинаковых правилах, когда выполнены условия уровня - переход к следующему level
			Цикл падения каждой фигуры - тактовый?
				Генерация фигуры
				Проверка (если уперлись сразу - выход из Раунда)
				Тактовый цикл
					Обработка действий пользователя
					Реализация игровых действий
					Проверки!
					Перерисовка
					Пауза
				Тактовый цикл	
				Касание низа
				Удаление фигуры и переход ее кубиков в слои
				Уничтожение кубиков/"гравитация" - цикл
				Очки и бонусы
			Следующая фигура
		Выполнены условия уровня? если да - новый level / нет - новая фигура
		Следующий уровень: ускорение, усложнение... 
	Если раунд полностью выполнен и не уперлись победа! - отчет.
	Выиграли - Финальная картинка раунда.
Конец игры
	Результаты
	Закончить/продолжить?
Финальная заставка
Выход
```

---

- Input layer (keyboard) - в своем потоке
собирает события,
кладет все их в queue.

- Game logic
Решает, что разрешено обработать сейчас.
Например:

Game policy:
maxHorizontalMoves = 1
maxRotations = 1

И забирает из очереди то, что можно обработать

Обрабатывает и передает в рендер
