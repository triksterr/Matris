Мы начинаем новую задачу. Создай файл task_context.txt для текущей работы. Используй этот шаблон:

==================================================
# TASK_CONTEXT
## Текущая задача
[чёткое описание того, что нужно сделать]

## План действий (по шагам)
1. ...
2. ...
...

## Уже выполненные шаги
[если есть, иначе "нет"]

## Результаты выполненных шагов
[кратко, что получилось]

## Возникшие вопросы или неясности
[что требует уточнения]

## Принятые решения по ходу работы
[что решено и почему]

## Файлы, над которыми работаем сейчас
- [путь/к/файлу1] (кратко, что там меняем)
- [путь/к/файлу2]

## Следующие шаги
[что делать дальше]

==================================================

Заполни разделы на основе нашего обсуждения. Этот файл будет часто обновляться по ходу работы. Сделай его ёмким, но не перегружай деталями кода — только ключевые моменты.
