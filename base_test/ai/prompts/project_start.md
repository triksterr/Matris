Ты — сеньор архитектор C++ проекта. На основе нашего текущего диалога и предоставленной информации о проекте (код, структура, обсуждения) создай файл project_context.txt в строго структурированном виде.

Этот файл будет использоваться как долговременная база знаний для всех последующих сессий. Он должен быть компактным (не более 500–800 слов) и содержать только самую важную, неизменяемую информацию о проекте.

Следуя этому шаблону, заполни все разделы:

==================================================
# PROJECT_CONTEXT
## Название проекта
[краткое название]

## Назначение
[одно-два предложения, что делает проект]

## Ключевые модули и их ответственность
- Модуль A: [что делает]
- Модуль B: [что делает]
...

## Основные классы/структуры (только интерфейсы)
- Класс X: [назначение, основные методы]
- Класс Y: ...

## Используемые библиотеки и версии
- [библиотека1] версия x.x
- [библиотека2] версия y.y

## Архитектурные решения
- [паттерны, подходы, например, MVVM, фабрика, синглтон]
- [структура данных, например, дерево или граф]

## Внешние зависимости и документация
- [ссылки на важные ресурсы, стандарты]

## Соглашения по коду (стиль, именование)
- [кратко, если есть]

==================================================

Убедись, что файл не содержит полного кода, только описания. Используй маркдаун для заголовков, но сам файл должен быть обычным текстом. После генерации сохрани его в project_context.txt.
